# ⚡ GridWeaver

### Hybrid Quantum-Classical Framework for Resilient Power Grid Restoration

GridWeaver is an interactive power grid restoration project that explores how classical optimization and quantum computing techniques can help identify restoration strategies during power outages.

The project combines power grid visualization, outage scenario simulation, restoration planning, and optimization result comparison in one platform.

## 🚀 Features

- **Grid Visualization:** Explore an interactive representation of a power grid.
- **Scenario Simulation:** Simulate power outages and examine their effects.
- **Restoration Planning:** Explore strategies for restoring affected grid components.
- **Classical Optimization:** Generate restoration plans using classical optimization techniques.
- **Quantum Optimization:** Explore QUBO formulations and QAOA-based optimization using a quantum simulator.
- **Scenario Comparison:** Compare available restoration results and performance metrics.
- **Analytics Dashboard:** Visualize relevant information and optimization results.
